
# yexcaのブログ

> 语言 / Language: [简体中文](README.zh-CN.md) | [English](README.md) | [繁體中文](README.zh-TW.md)

ようこそ、私のブログ倉庫へ！

ここでは、学習・生活・開発の過程での思考や記録、そして創作などをまとめています。  
ブログは多言語に対応しており、現在は簡体字中国語・繁體字中国語・日本語・英語をサポートしています（すべての記事に多言語版があるとは限りません）。

## ✨ 特徴

- 📚 多言語対応（Hugo + i18n）
- 🛠 カスタムテーマ＆カテゴリ・タグ分類の最適化
- 💡 技術メモ / 生活に関する考察
- 🗂 シンプルかつ明快な構成、閲覧・二次開発にも適応
- 同一オリジンのソフトナビゲーション：ブラウザ履歴、スクロール位置の復元、View Transition、フォールバックに対応
- コードブロック機能を拡張：コピー、折り返し、折りたたみ、独立ウィンドウモード
- ビルド出力、検索インデックス、アセット、フォント、サードパーティスクリプトを確認するパフォーマンス保守フロー

## 🗃 ディレクトリ構成

- `content/`：記事本体。言語ごとに分かれています
- `themes/`：テーマは [stack](https://github.com/CaiJimmy/hugo-theme-stack) をベースにカスタマイズ
- `static/`：静的ファイル
- `docs/`: 現在のリファクタリング後ブログの保守ドキュメント
- `scripts/`: パフォーマンスレポートなどのローカル保守スクリプト
- `hugo.yml`：ブログの設定ファイル

## 🧩 使用技術

- Hugo 静的サイトジェネレーター
- GitHub Actions による自動デプロイ

## 📄 ドキュメント

まず [docs/README.md](docs/README.md) を参照してください。現在のドキュメントには次の内容があります。
