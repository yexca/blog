However, as of August 11, 2022, Bilibili's (~~when is it shutting down?~~) default embed link defaults to 360P and doesn't allow quality adjustments. It’s pretty frustrating compared to YouTube. Below are the parameters and methods for customizing Bilibili's embed links.

### Bilibili Embed Key Reference

| Key | Description |
|---|---|
| aid | The old AV ID format used by Bilibili |
| bvid | The current BV ID format |
| page | Video index in a series, starting from 1 (default is 1) |
| as\_wide | Widescreen mode [1: Widescreen, 0: Standard] |
| high\_quality | High quality [1: High quality (up to 1080p) / 0: Lowest quality (default)] |
| danmaku | Toggle bullet comments [1: On (default), 0: Off] |
| vd\_source=XXX&amp;t=XXX | Can be used for specific timestamp jumping |
