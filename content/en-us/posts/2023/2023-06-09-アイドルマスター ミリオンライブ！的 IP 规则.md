## Clash

It's better to manage this via proxy groups.

First, set up the JP group:

```yaml
proxy-groups:
- name: JP
  type: select
  proxies:
  - your jp proxy name
  - your jp proxy name
```

Then add the rule:

```yaml
rules:
  - DOMAIN-SUFFIX,theaterdays.appspot.com,JP
```
