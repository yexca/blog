## ngrok OneClick

1. Go to the [official website](https://ngrok.com/), register an account, and verify your email to get your *Authtoken*.

2. Download the client: [ngrok - download](https://ngrok.com/download)

3. Add Your Token

```bash
ngrok config add-authtoken YourToken
```

4. Run It

```bash
ngrok http [Port]
```

Replace `[Port]` with the local port you want to expose.
