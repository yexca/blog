## ngrok ワンクリック

1. [公式サイト](https://ngrok.com/)でアカウント登録してメール認証すると、*Authtoken*がもらえるよ。

2. プログラムをダウンロード：[ngrok - download](https://ngrok.com/download)

3. トークンを追加

```bash
ngrok config add-authtoken YourToken
```

4. 実行

```bash
ngrok http [Port]
```

[Port] を、リッスンしたいローカルポートに置き換えてね。
