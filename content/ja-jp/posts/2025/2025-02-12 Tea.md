## 紅茶

| 名前     | 味                                                         |
| -------- | ------------------------------------------------------------ |
| 妃子笑   | 最初はなんか重くてしつこい感じの味<br/>何回か淹れたらサツマイモみたいな味になった<br/>だいたい12煎くらいかな |
| 水蜜桃   | 初めて淹れた時、『妃子笑』よりちょっと苦くて、しつこくなかった<br/>*夜に呼吸が苦しくなって、血が出た。お茶のせいかは不明* |
| 昔帰紅   | 最初は甘くてしつこくなく、苦くなくて渋みもなくて、すごく良かった |
| 祁門紅茶 | 最初は『昔帰紅』と似た感じ、甘くはないけど、たぶんもっとまろやか<br/>でも茶葉はかなり細かかった |
| 金駿眉   | まろやかすぎ、むしろちょっと苦渋い。でも3杯目以降は口の中に香りと甘みが残る<br/>茶葉は細かくて、淹れる回数もそんなに多くない |
| 酔紅     | まさに紅茶の味<br/>煎数はまあまあいけるけど、蒸らしすぎはダメ。茶殻が多め |
| 煙熏小種 | *確かに燻製っぽい匂いがする*<br />口に入れた瞬間は苦いけど、後味が甘い                     |
| 老叢紅茶 | 美味しい                                                         |
