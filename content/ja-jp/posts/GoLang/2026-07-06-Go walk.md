## 環境

GoLandで新しいGoプロジェクトを作成すると、デフォルトで `go.mod` が初期化されます。もしこのファイルがない場合は、以下のコマンドを使用できます。

```bash
go mod init
```

walkのインストール

```bash
go get github.com/tailscale/walk
```

## プロジェクト

[rsrc ツール](https://github.com/akavel/rsrc)をダウンロードしてPATHを通した後、rsrcをインストールします。

```bash
go get github.com/akavel/rsrc
```

マニフェストファイル `main.manifest` を作成し、内容は以下の通りとします。

```
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<assembly xmlns="urn:schemas-microsoft-com:asm.v1" manifestVersion="1.0">
    <assemblyIdentity version="1.0.0.0" processorArchitecture="*" name="SomeFunkyNameHere" type="win32"/>
    <dependency>
        <dependentAssembly>
            <assemblyIdentity type="win32" name="Microsoft.Windows.Common-Controls" version="6.0.0.0" processorArchitecture="*" publicKeyToken="6595b64144ccf1df" language="*"/>
        </dependentAssembly>
    </dependency>
    <application xmlns="urn:schemas-microsoft-com:asm.v3">
        <windowsSettings>
            <dpiAwareness xmlns="http://schemas.microsoft.com/SMI/2016/WindowsSettings">PerMonitorV2, PerMonitor</dpiAwareness>
            <dpiAware xmlns="http://schemas.microsoft.com/SMI/2005/WindowsSettings">True</dpiAware>
        </windowsSettings>
    </application>
</assembly>
```

Goプログラムへのマージ

```
rsrc -manifest main.manifest -o rsrc.syso
```

## カウントダウン開発

```go
package main

import (
	"fmt"
	"github.com/tailscale/walk"
	. "github.com/tailscale/walk/declarative"
	"log"
	"runtime"
	"time"
)

func main() {
	app, err := walk.InitApp()
	if err != nil {
		log.Fatal(err)
	}

	var timeRemain *walk.Label
	var flag bool
	ok := true

	MainWindow{
		Title:   "Hi walk",                   // ウィンドウタイトル
		MinSize: Size{Width: 60, Height: 40}, // 最小サイズ
		Layout:  VBox{MarginsZero: true},     // ウィンドウレイアウト、垂直ボックスレイアウト
		Children: []Widget{
			Label{
				AssignTo: &timeRemain,
				Text:     "カウントダウン開始 10秒",
			},
			PushButton{
				Text: "カウントダウン開始",
				OnClicked: func() {
					if flag {
						return
					}
					flag = true
					// カウント
					go func() {
						for i := 10; i > 0; i-- {
							if ok {
								time.Sleep(1 * time.Second)
								timeRemain.SetText(fmt.Sprintf("カウントダウン %d 秒", i))
							} else {
								runtime.Goexit()
							}
						}
						walk.MsgBox(nil, "通知", "時間です", walk.MsgBoxIconInformation)
						flag = false
					}()
				},
			},
			PushButton{
				Text: "カウントダウン停止",
				OnClicked: func() {
					flag = false
					ok = false
					timeRemain.SetText("カウントは停止しました")
					time.Sleep(1 * time.Second)
					timeRemain.SetText("カウントダウン開始 10秒")
				},
			},
		},
	}.Create()

	app.Run()
}
```

## 新しいウィンドウ

新しいウィンドウを開く

```go
package main

import (
	"github.com/tailscale/walk"
	. "github.com/tailscale/walk/declarative"
	"log"
)

type MyMainWindow struct {
	*walk.MainWindow
}

func main() {
	app, err := walk.InitApp()
	if err != nil {
		log.Fatal(err)
	}

	mw := new(MyMainWindow)

	MainWindow{
		AssignTo: &mw.MainWindow,
		Title:    "Hi walk",                     // ウィンドウタイトル
		MinSize:  Size{Width: 400, Height: 500}, // 最小サイズ
		Size:     Size{Width: 400, Height: 500}, // サイズ
		Layout:   VBox{},                        // ウィンドウレイアウト
		Children: []Widget{
			Label{
				Text:      "モードを選択してください",
				Alignment: AlignHCenterVCenter,
			},
			PushButton{
				Text:      "短時間・高頻度の休憩",
				OnClicked: mw.shortLayout,
			},
			PushButton{
				Text: "長時間・低頻度の休憩",
			},
		},
	}.Create()

	app.Run()

}

func (mw *MyMainWindow) shortLayout() {
	shortMainWindow := new(MyMainWindow)
	MainWindow{
		AssignTo: &shortMainWindow.MainWindow,
		Title:    "短時間・高頻度の休憩",
		MinSize:  Size{Width: 400, Height: 500}, // 最小サイズ
		Size:     Size{Width: 400, Height: 500}, // サイズ
		Layout:   VBox{},
		Children: []Widget{
			Label{Text: "Hello"},
		},
	}.Create()

	shortMainWindow.Running()
}

```
