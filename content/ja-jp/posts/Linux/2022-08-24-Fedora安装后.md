## ユーザーディレクトリを英語に変更

日本語のディレクトリって、ターミナルで操作するのがすごく大変なんだよね。

まず言語を英語に変更するよ。

```bash
export LANG=en_US
```

それからユーザーディレクトリを更新。

```bash
xdg-user-dirs-gtk-update
```

この時、ユーザーディレクトリ下のフォルダを英語に変更するかどうか聞かれるから、「はい」を選んでね。

次にシステム言語を日本語に戻すよ。

```bash
export LANG=zh_CN.UTF-8
```

もう一度ユーザーディレクトリの更新コマンドを実行。

```bash
xdg-user-dirs-gtk-update
```

もう一度上のコマンドを入力すると、日本語に変更するかどうか聞かれるから、「いいえ」を選んで、「今後表示しない」にチェックを入れればOK。

## VsCode

環境設定

```bash
sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
```

```bash
sudo sh -c 'echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" > /etc/yum.repos.d/vscode.repo'
```

キャッシュを更新

```bash
dnf check-update
```

`dnf`でインストールするなら

```bash
sudo dnf install code
```

`yum`を使うなら

```bash
yum check-update
sudo yum install code
```

## 網易雲音楽

flatpakのインストールと設定

```bash
sudo dnf install flatpak
```

```bash
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

netease.CloudMusicのインストール

```bash
flatpak install flathub com.netease.CloudMusic
```

実行／アイコンをクリックして実行

```bash
flatpak run com.netease.CloudMusic
```

アンインストール

```bash
flatpak uninstall com.netease.CloudMusic
```

## Nvidiaドライバーのインストール

インストール

```bash
sudo dnf install akmod-nvidia
```

オプションだよ

```bash
sudo dnf install xorg-x11-drv-nvidia-cuda
```

インストールが終わったら再起動してね。

```bash
reboot
```

ノート：*もし再起動後に「Nvidia kernel module missing falling back to Nouveau」と表示されたら*

1. **まずBIOSでセキュアブートが無効になっているか確認してね**

2. `rpm -qa akmods`を実行して、インストールされている`akmods`パッケージのバージョンをチェック。

3. `sudo akmods --force && sudo dracut --force`を実行して、カーネルモジュールをビルドしてね。

> 参考にしたのはここ：[Fedora 34 NVIDIA kernel module missing. Falling back to nouveau - #4，来自 vk2bea - Ask Fedora](https://ask.fedoraproject.org/t/fedora-34-nvidia-kernel-module-missing-falling-back-to-nouveau/13785/4)

もし上記の方法でダメだったら、以下の方法を試してみてね。

1. Nvidia関連のものを全部アンインストールするよ。`sudo dnf remove \*nvidia\*`

2. ドライバーをインストール。`sudo dnf install akmod-nvidia`

> 参考にしたのはここ：[Nvidia kernel module missing falling back to Nouveau (Fedora 36 PR) : Fedora](https://www.reddit.com/r/Fedora/comments/t7w5j3/nvidia_kernel_module_missing_falling_back_to/)
