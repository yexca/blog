## 引言

由於 QQ 軟體過於臃腫且權限過大，並且經常性卡住無法載入，因此便尋找其他方法。首先是透過 Telegram 收發 QQ 訊息，但設定較為複雜且並不穩定，於是棄用並改用 VS Code。

## 插件簡介

名稱: QQ  
ID: takayama.vscode-qq  
說明: lite qq for chat in working  
版本: 1.4.2  
發布者: takayama  
VS Marketplace 連結: [VS Code QQ Extension](https://marketplace.visualstudio.com/items?itemName=takayama.vscode-qq)  
GitHub 專案位址：[vscode-qq](https://github.com/takayama-lily/vscode-qq)

註：本程式不在本地儲存任何訊息紀錄和圖片。暫不支援臨時對話。

## 安裝

首先安裝 VS Code，造訪[官網](https://code.visualstudio.com/)點擊 Download 即可下載安裝。

然後造訪上述 [VS Code QQ Extension](https://marketplace.visualstudio.com/items?itemName=takayama.vscode-qq) 連結點擊 Install 即可自動開啟 VS Code 安裝。

或者打開 VS Code 在左側「延伸模組」(或按 CTRL+SHIFT+X)，然後搜尋 QQ (注意大寫)，點擊第一個安裝。

## 功能

按快速鍵「CTRL+SHIFT+P」打開命令面板。

輸入「QQ Explorer: Login」（或只輸入「login」會顯示對應選項）後按 Enter。

然後根據提示輸入帳號密碼即可登入成功，此時會顯示相關功能。

輸入「QQ Explorer: 搜尋好友」即可搜尋好友。

輸入「QQ Explorer: 搜尋群組」即可搜尋群組。

## 設定

在登入成功後控制面板便會有設定，進入設定為 JSON 檔案編輯，內容如下：

```json
{
  "account": ***********, // QQ 號碼
  "password": "********************************", // QQ 密碼
  "platform": 5, // 登入平台，可更改「1: 手機, 3: 手錶(功能不完整), 4: PC, 5: pad(預設)」
  "show_me_add_group_request": false,
  "theme": "default", // UI 主題，可更改「default(預設) 和 console(控制台風格)」
  "theme_css": "",
  "theme_js": ""
}
```

可自訂主題，詳情參考：**[修改/自定義 UI 主題](https://github.com/takayama-lily/vscode-qq/wiki/%E8%87%AA%E5%AE%9A%E4%B9%89%E8%81%8A%E5%A4%A9UI%E7%95%8C%E9%9D%A2)**
