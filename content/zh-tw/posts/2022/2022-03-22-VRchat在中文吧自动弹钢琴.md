## 如果不使用 MIDI 檔案

### 一、準備

為了實現鋼琴自動彈奏，需要安裝兩個軟體、一個外掛

#### 1）loopMIDI

此軟體可在官網直接取得，官網連結：[loopMIDI-Tobias Erichsen (tobias-erichsen.de)](https://www.tobias-erichsen.de/software/loopmidi.html)

檔案直接下載連結：[loopMIDISetup\_1\_0\_16\_27.zip](https://www.tobias-erichsen.de/wp-content/uploads/2020/01/loopMIDISetup_1_0_16_27.zip)（可能因版本更新而失效）

#### 2）Jazz-Plugin

安裝時請保持預設安裝路徑，否則可能無法正常使用

Windows: [點此下載（外掛官網連結）](https://jazz-soft.net/download/Jazz-Plugin/1.5.1/Jazz-Plugin-1-5-1.msi) （如果官網連結無法下載，也可 [點此下載](https://sc.midishow.net/static/Jazz-Plugin-1-5-1.msi) ）

Mac OS X: [點擊下載](https://jazz-soft.net/download/Jazz-Plugin/1.5.1/Jazz-Plugin-1-5-1.dmg)

Linux 版本：[點擊下載](https://jazz-soft.net/download/Jazz-Plugin/1.5.1/Jazz-Plugin-1-5-2.sh)

#### 3）瀏覽器外掛 Jazz-MIDI

文章最初連結的 Jazz-MIDI Chrome 擴充功能目前無法直接安裝到新版 Chrome。可以從作者的[開源儲存庫](https://github.com/jazz-soft/jazz-midi)自行建置。

##### 從原始碼建置（Windows）

1. 安裝 Git 和 Visual Studio，並確保已安裝 C++ 桌面開發工具。

2. 複製儲存庫：

   ```powershell
   git clone https://github.com/jazz-soft/jazz-midi.git
   cd jazz-midi
   ```

3. 開啟開始功能表中的 `x64 Native Tools Command Prompt for VS 2022`，進入儲存庫的 `native` 目錄並建置（請將路徑替換為實際的儲存庫位置）：

   ```bat
   cd /d C:\path\to\jazz-midi\native
   nmake /f Makefile.Windows
   ```

   建置完成後會得到 `native\jazz-midi.exe` 和 `native\manifest.exe`。Chrome 擴充功能原始碼位於 `firefox\jazz-midi` 目錄，專案不需要額外的 JavaScript 打包步驟。

4. 在 Chrome 網址列開啟 `chrome://extensions`，啟用「開發人員模式」，點擊「載入已解壓縮的擴充功能」，選擇儲存庫中的 `firefox\jazz-midi` 目錄。

   如果電腦上已經安裝過 Jazz-Plugin，Native Messaging 主機通常已經完成註冊，可以直接在 MidiShow 中測試。只有在擴充功能無法連線本機 MIDI 主機，或 MidiShow 沒有顯示 MIDI 裝置時，才需要繼續進行下面的設定。

##### 如果擴充功能無法正常使用

1. 在 `native` 目錄執行以下命令產生 Native Messaging 主機設定（請將路徑替換為實際位置）：

   ```bat
   manifest.exe com.jazz_soft.jazz_midi "C:\path\to\jazz-midi\native\jazz-midi.exe"
   ```

2. 開啟產生的 `com.jazz_soft.jazz_midi.chrome.json`，將 `allowed_origins` 中的擴充功能 ID 改成 Chrome 在 `chrome://extensions` 中顯示的本機擴充功能 ID。

3. 將設定註冊到目前使用者的 Chrome：

   ```bat
   reg add "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.jazz_soft.jazz_midi" /ve /t REG_SZ /d "C:\path\to\jazz-midi\native\com.jazz_soft.jazz_midi.chrome.json" /f
   ```

4. 重新啟動 Chrome 後再次測試。

### 二、步驟

#### 1）開啟 loopMIDI，新增項目

新增項目時，先在右下角 `New port-name` 輸入名稱，再點擊左下角 `+`（加號）即可

![loopMIDI_新建](https://cdn.jsdelivr.net/gh/yexca/picx-images-hosting@master/2022/03-VRChat弹钢琴/loopMIDI_新建.png)

完成後，項目會出現在上方，這裡以 `Hello World` 為項目名稱

![loopMIDI_Hello-World](https://cdn.jsdelivr.net/gh/yexca/picx-images-hosting@master/2022/03-VRChat弹钢琴/loopMIDI_Hello-World.png)

#### 2）開始播放

##### <1> 找到待播放的歌曲

首先，開啟網站 [MidiShow – 領先的 MIDI 音樂交流與下載網站](https://www.midishow.com/)

註冊登入後搜尋想播放的歌曲

##### <2> 進行播放設定

如圖所示，以 `Hand in Hand` 為例，點擊 `播放設定` 按鈕

![image](https://cdn.jsdelivr.net/gh/yexca/picx-images-hosting@master/2022/03-VRChat弹钢琴/image.6snx05xtm340.png)

設定如圖，`MIDI 輸出裝置` 選擇剛剛使用 loopMIDI 新增的項目，這裡為 `Hello World`

![image](https://cdn.jsdelivr.net/gh/yexca/picx-images-hosting@master/2022/03-VRChat弹钢琴/image.40sel5s9j3m0.png)

##### <3> 開始播放

此時進入中文吧鋼琴旁，選取板凳坐上去，然後在網頁中點擊播放即可

## 如果使用 MIDI 檔案

首先，請確保 MIDI 檔案為鋼琴譜，多軌檔案可能會發生混亂，請自行編輯

### 一、準備

#### 1）loopMIDI

此軟體可在官網直接取得，官網連結：[loopMIDI-Tobias Erichsen (tobias-erichsen.de)](https://www.tobias-erichsen.de/software/loopmidi.html)

檔案直接下載連結：[loopMIDISetup\_1\_0\_16\_27.zip](https://www.tobias-erichsen.de/wp-content/uploads/2020/01/loopMIDISetup_1_0_16_27.zip)（可能因版本更新而失效）

#### 2）MidiPiano

此軟體我在某個下載軟體網站取得（Google 搜尋結果第一個）

網站連結：[MidiPiano – Download (softonic.com)](https://midipiano.en.softonic.com/)

### 二、步驟

#### 1）在 loopMIDI 中新增項目

新增項目時，先在右下「New port-name」輸入名稱，再點擊左下「+」（加號）即可

![loopMIDI_新建](https://cdn.jsdelivr.net/gh/yexca/picx-images-hosting@master/2022/03-VRChat弹钢琴/loopMIDI_新建.png)

完成後，項目會出現在上方，這裡以「Hello World」為項目名稱

![loopMIDI_Hello-World](https://cdn.jsdelivr.net/gh/yexca/picx-images-hosting@master/2022/03-VRChat弹钢琴/loopMIDI_Hello-World.png)

#### 2）開啟 MidiPiano，進行設定

點擊播放清單，可直接將檔案拖入；點擊選項，將輸出裝置設定為剛剛 loopMIDI 建立的項目，此處為 `Hello World`

![image](https://cdn.jsdelivr.net/gh/yexca/picx-images-hosting@master/2022/03-VRChat弹钢琴/image.6wnkq7erta80.png)

##### 如果出現彈出視窗「MIDI 輸入輸出不能為同一個，會當機的！」

請點擊選項中的 `Midi 輸入裝置`，取消剛剛 loopMIDI 建立的項目，然後再切換至 `Midi 輸出裝置` 將其開啟

#### 3）開始播放

此時進入中文吧鋼琴旁，選取板凳坐上去，然後選擇 `播放清單` 中想播放的歌曲，再點擊 `播放` 即可
