## 登入 Docker Hub

貌似安裝 Docker 後使用 `docker pull` 要先登入

首先到官網註冊帳號：[Docker Hub](https://hub.docker.com/)

然後需要先進行初始化，執行命令

```bash
gpg --generate-key
```

輸入相關資訊後注意輸出的 *pub* 下一行的一串字串，複製並替換為下述命令的 *[pub]*

```bash
pass init [pub]
```

然後在 Docker Desktop 登入

## 音聲 - kikoeru-express

Docker Hub：[muveex/kikoeru-express](https://hub.docker.com/r/muveex/kikoeru-express)

Github：[kikoeru-project/kikoeru-express](https://github.com/kikoeru-project/kikoeru-express)

我下載的是 0.6.2 版本 ~~(話說這東西和某網站很像嘛)~~
