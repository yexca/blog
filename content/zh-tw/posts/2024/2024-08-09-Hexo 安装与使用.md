## 環境

需要安裝 Node.js 10.13 以上版本，推薦 12.0 以上。

需要安裝 Git。

## 安裝

執行指令：

```bash
npm install -g hexo-cli
```

檢查安裝是否成功：

```bash
hexo -h
```

## 建立新部落格

切換到要安裝的資料夾：

```bash
hexo init <folder_name>
```

進入資料夾：

```bash
cd <folder_name>
```

安裝相依套件：

```bash
npm i
```

建立完成後可以修改 `./_config` 進行設定。

## 安裝主題

到[主題站](https://hexo.io/themes/)挑選一個主題，不同主題可能有不同的安裝方法，具體請參考主題文件。

以下為 Argon 主題的安裝範例：

### 複製主題

首先在 `./themes` 資料夾複製主題儲存庫：

```bash
git clone https://github.com/solstice23/hexo-theme-argon.git
```

將複製下來的資料夾重新命名為 `argon`。

安裝 ejs 渲染器：

```bash
npm install hexo-renderer-ejs
```

在 `./_config.yml` 檔案中將 theme 改為 argon。

### 設定檔

修改檔案 `./themes/argon/_config.yml` 以更改設定。

### 設定搜尋

在根目錄執行：

```bash
npm install hexo-generator-search --save
```

然後在 `./_config.yml` 中加入選項：

```bash
search:
  path: search.xml
  field: post
  content: true
```

## 寫作

建立新文章：

```bash
hexo new [layout] <title>
```

其中 `[layout]` 是一個可選屬性，具體如下：

| Layout | 描述       | 路徑           |
| ------ | ---------- | -------------- |
| post   | 文章，預設 | source/_posts  |
| page   | 頁面       | source         |
| draft  | 草稿       | source/_drafts |

建立完成後即可開始編寫文章。

預覽：

```bash
hexo s
```

存取 localhost:4000 查看效果。

## 產生靜態檔案

執行指令：

```bash
hexo generate
```

執行指令後只會針對有變動的部分進行產出，建議先將原有的刪除再重新產生會比較好。
