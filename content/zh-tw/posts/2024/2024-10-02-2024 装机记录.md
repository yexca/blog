## 系統

> 2024.10.03

## 辦公軟體

基礎的 Office 必不可少，採用 Office Tool 進行安裝方便快速。

以下內容僅安裝 Word、Excel 和 PowerPoint。

下載 Office Tool: <https://otp.landian.vip/zh-cn/download.html>

啟動 Office Tool，執行程式碼安裝：

```bat
deploy /add O365ProPlusRetail_zh-cn /O365ProPlusRetail.exclapps Access,Bing,Groove,Lync,OneDrive,OneNote,Outlook,Publisher,Teams /channel Current /dlfirst
```

利用 kms 啟動 Office，執行程式碼啟動：

```bat
ospp /inslicid MondoVolume /sethst:kms.loli.beer /setprt:1688 /act
# or use kms.03k.org
ospp /inslicid MondoVolume /sethst:kms.03k.org /setprt:1688 /act
```

## 下載工具與雲端硬碟

迅雷: 使用的是忘了從哪找的精簡版。雖然會吸血，但有些東西確實還是得用迅雷下載。

BitComet: BT 下載工具，同樣使用了精簡版。類似的工具有 qBittorrent, µTorrent 等。

[Resilio Sync](https://www.resilio.com/sync/download/): 基於 BT 技術的同步軟體，方便各端檔案同步。

Internet Download Manager: 即 IDM，比較好用的多執行緒下載工具。

[115](https://115.com/): 用於下載一些下不動的 BT。類似的工具有 pikpak。

[百度網盤](https://pan.baidu.com/disk/main): 開了會員很好用，但沒會員就是折磨。時間，加錢可得。與之類似的如阿里網盤、夸克網盤可以在需要時再下載。

## 解壓縮工具

之前的電腦上倒是裝了不少的解壓縮工具，但實際上使用的也就兩個，於是這次就只裝兩個了。

[Bandizip](https://cn.bandisoft.com/bandizip/): 應該是較為流行的吧，之前當我剛聽說時學校電腦教室都用上了。

WinRAR: 比較古老的軟體，但有些 rar 只有使用此軟體才能解壓縮。

其他的:

- [7-zip](https://www.7-zip.org/): 最為流行的解壓縮軟體。
- [NanaZip](https://github.com/M2Team/NanaZip): 7z 的美化版，並且可以在 Win11 第一層右鍵選單顯示。

## 其他工具

[Utools](https://www.u.tools/download/): 非常便捷的工具，官網有動畫介紹，透過外掛擴充使其非常方便，比如本文就是使用其 MarkDown 擴充寫的，雖然有些地方不如 Typora 但勝在方便。

[QuickLook](https://github.com/QL-Win/QuickLook/releases): 快速預覽檔案的工具，用起來不是太理想，希望未來可以找到替代品。非安裝版需要解鎖後使用: <https://github.com/QL-Win/QuickLook/issues/1>

[1Password](https://1password.com/zh-cn): 密碼管理工具，可以使用開源替代品 [bitwarden](https://bitwarden.com/)。我已經徹底離不開密碼管理器啦。

PDF 閱讀器: 感覺大部分都差不多，隨緣用用。

- Foxit PDF
- Wondershare PDFelement
- PDF XChange

[sandboxie](https://sandboxie-plus.com/downloads/): 沙盒工具，對於不想直接在電腦上執行而污染環境的程式很好用，非安裝版每次執行需要管理員權限。

[TickTick](https://ticktick.com/download): To Do List 軟體，全平台同步，不過最近感覺同步不是太順暢。

[QuiteRSS](https://github.com/QuiteRSS/quiterss): RSS 訂閱管理工具，但介面較為古老，不過由於我使用習慣了也無所謂。畢竟轉移只需壓縮解壓縮，RSS 訂閱也不會遺失。

Duplicate Cleaner Pro: 之前用的清理軟體找不到了，就用八醬的這個啦。雖然有些時候不是太好用，但使用久了後還行吧。

[PixPin](https://pixpinapp.com/): 螢幕截圖工具。

## 部落格

因為我部落格使用 Jekyll 框架，還需要重新安裝一下，希望不要出問題。

執行環境

- Ruby: <https://www.ruby-lang.org/en/downloads/>
- RubyGems: <https://rubygems.org/pages/download>
- Node.js: <https://nodejs.org/zh-tw>

安裝 Jekyll

```bat
gem install jekyll
```

初始化部落格

```bat
bundle
```

好吧，有幾個外掛我重啟也裝不上，同時參考了 [Installation Issues on MacOSX - Gem::Ext::BuildError: ERROR: Failed to build gem native extension](https://talk.jekyllrb.com/t/installation-issues-on-macosx-gem-error-failed-to-build-gem-native-extension/4545) 等文章也無法安裝。

經朋友的提醒，確實還是得用 Docker 比較好，天天搞環境會煩死，明明專案都用 Docker 我部落格居然還在用在地安裝。

---

參考我[主題安裝文章](https://chirpy.cotes.page/posts/getting-started/)安裝 VS Code 外掛 [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers) 用於查看容器內部檔案。

打開 VS Code 按下 `F1` 輸入 `Dev Containers: Clone Repository in Container Volume...` 選擇後輸入一個 Git 連結 (即我的 blog 的原始碼)。

等待一會後 (右下角可以看日誌) 選擇要使用的系統、軟體等配置，我選擇 Debian 系統，軟體我沒選。

首先更新軟體：

```bash
sudo apt-get update
```

參考[官方教學](https://jekyllrb.com/docs/installation/other-linux/)安裝 Jekyll：

```bash
sudo apt-get install ruby-full build-essential
# 上方是依賴項目
sudo gem install jekyll bundler
```

安裝 NodeJS：

```bash
sudo apt install nodejs
```

安裝依賴項目：

```bash
sudo bundle
```

> 會提示不要用 root 權限執行，但這只是容器，隨便弄，無視。

嘗試部署專案：

```bash
bundle exec jekyll s
```

專案成功執行，~~但因為是容器的連接埠，需要映射到本機才能看~~，打開直接能看，VS Code nb (doge)。

感覺比 Win 編譯的要快，非常 Nice。
