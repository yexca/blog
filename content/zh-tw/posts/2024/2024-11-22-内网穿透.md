## ngrok 一鍵設定

1. 前往[官網](https://ngrok.com/)註冊帳號並驗證電子郵件後會取得 *Authtoken*

2. 下載程式：[ngrok - download](https://ngrok.com/download)

3. 新增 Token

```bash
ngrok config add-authtoken YourToken
```

4. 執行

```bash
ngrok http [Port]
```

將 [Port] 替換成要監聽的本機埠號
