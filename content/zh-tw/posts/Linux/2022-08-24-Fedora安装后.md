## 將使用者目錄改為英文

中文目錄在使用終端機操作時非常不便。

首先將語系改為英文：

```bash
export LANG=en_US
```

然後更新使用者目錄：

```bash
xdg-user-dirs-gtk-update
```

這時，系統會提示您是否要將使用者目錄下的資料夾改為英文，請選擇「是」。

然後再將系統語系切換回中文：

```bash
export LANG=zh_CN.UTF-8
```

再次執行更新使用者目錄的指令：

```bash
xdg-user-dirs-gtk-update
```

再次輸入上述指令時，系統會提示您是否要改回中文，請選擇「否」，並勾選「不再提醒」即可。

## VsCode

設定環境

```bash
sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
```

```bash
sudo sh -c 'echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" > /etc/yum.repos.d/vscode.repo'
```

重新整理快取

```bash
dnf check-update
```

使用`dnf`安裝

```bash
sudo dnf install code
```

或者使用`yum`

```bash
yum check-update
sudo yum install code
```

## 網易雲音樂

安裝與設定 Flatpak

```bash
sudo dnf install flatpak
```

```bash
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

安裝 netease.CloudMusic

```bash
flatpak install flathub com.netease.CloudMusic
```

執行／點擊圖示執行

```bash
flatpak run com.netease.CloudMusic
```

解除安裝

```bash
flatpak uninstall com.netease.CloudMusic
```

## NVIDIA 驅動程式安裝

安裝

```bash
sudo dnf install akmod-nvidia
```

選用

```bash
sudo dnf install xorg-x11-drv-nvidia-cuda
```

安裝完成後重新啟動

```bash
reboot
```

note: *如果重新啟動後顯示「Nvidia kernel module missing falling back to Nouveau」*

1. **首先請確保在 BIOS 中停用 Secure Boot**

2. Check the version of `akmods` package installed by running `rpm -qa akmods`

3. Run `sudo akmods --force && sudo dracut --force` to build the kernel modules

> 此處參考：[Fedora 34 NVIDIA kernel module missing. Falling back to nouveau - #4，來自 vk2bea - Ask Fedora](https://ask.fedoraproject.org/t/fedora-34-nvidia-kernel-module-missing-falling-back-to-nouveau/13785/4)

如果上述方法無效，請嘗試使用以下方法：

1. 解除安裝所有與 NVIDIA 相關的套件：`sudo dnf remove \*nvidia\*`

2. 安裝驅動程式：`sudo dnf install akmod-nvidia`

> 此處參考：[Nvidia kernel module missing falling back to Nouveau (Fedora 36 PR) : Fedora](https://www.reddit.com/r/Fedora/comments/t7w5j3/nvidia_kernel_module_missing_falling_back_to/)
